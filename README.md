# Agenda de Colaboradores

Proyecto realizado para el curso de Desarrollo Web utilizando Python, Flask, HTML, CSS y Bootstrap.

## Descripción

La aplicación permite registrar colaboradores con su nombre, apellido, fecha de nacimiento y día de trabajo.

Los datos se guardan en un archivo de texto llamado `colaboradores.txt`.

También se puede ver la lista de colaboradores registrados, su edad calculada y un resumen de cuántos colaboradores trabajan cada día.

## Funciones

- Registrar colaboradores.
- Guardar los datos en un archivo de texto.
- Mostrar los colaboradores registrados.
- Calcular la edad de cada colaborador.
- Mostrar un resumen por día de la semana.

## Ejecutar el proyecto

Instalar Flask:

`pip install flask`

Ejecutar:

`python app.py`

Luego ingresar a:

`http://127.0.0.1:5000`
